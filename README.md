# 屏幕词典

在菜单栏切换「弹出词典」和「屏幕翻译」。首次打开设置后授予「屏幕录制」权限。使用鼠标组合键还需在「辅助功能」里授权。

- 弹出词典。指向一个词后按 `⌥S` 或 `⌥ + 左键`，原词高亮，旁边显示所在句子的译文。用 Apple 本机翻译时，可以点「查看语境释义」按需用模型补充当前词义并高亮译词。
- 英语查简体中文时，匹配到词条会先显示本机词典释义。离线词条来自 [ECDICT](https://github.com/skywind3000/ECDICT/tree/39cfb9672c0906b63569e0453c2e6abfb9ab182a)，应用内附 MIT 许可。
- 屏幕翻译。指向文字块触发会翻译该块。指向空白或使用手柄触发会翻译整屏。
- 点击结果区以外的位置，鼠标松开后回到原应用。`Esc` 也能收起覆盖层。

两种模式分别选择译文引擎和译入语。macOS 26 及更新版本默认使用 Apple 本机翻译，可在系统设置的「通用 → 语言与地区 → 翻译语言」管理语言包。「模型翻译」及按需语境释义支持 Ollama 和支持 JSON 输出的兼容服务。密钥存入系统钥匙串。截图、原文和译文随本次覆盖层会话释放。

## 构建

应用可运行在 macOS 15 或更新版本。构建需要 Swift 6 和 macOS 26 或更新版本的 SDK。

```sh
./build-app.sh "$PWD/屏幕词典.app"
open "$PWD/屏幕词典.app"
```

仓库包含构建用的本机词库及其[许可证](Packaging/Resources/ECDICT-LICENSE.txt)。脚本使用本机架构生成 `.app`，优先用可用的 Apple Development 证书签名，也可以通过 `SCREEN_DICTIONARY_SIGNING_IDENTITY` 指定。更新时沿用同一包标识与签名身份，有助于系统保留既有授权。
